ASIC · Tapeout TSMC 180 nm

4-bit 4×4 Matrix-Multiplication Accelerator

Designed and taped out a matrix-multiplication accelerator with SPI loading and readback, register-based matrix storage, FSM-controlled dot products, and a 10-bit accumulator. Completed RTL verification, synthesis, floorplanning, CTS, routing, extraction, and physical signoff.

Result: sign-off setup WNS 5.218 ns and hold WNS 0.113 ns at 100 MHz, TNS 0 across all 639 paths; 72.18% density, 9.84 mW at 1.8 V, 680 × 670 µm core, and clean Calibre DRC / LVS / antenna. Silicon testing runs in fall 2026.

SystemVerilog, Xcelium, Genus, Innovus, Calibre

Memory Design Transistor Level

16×4 Synchronous 6T SRAM Macro

Designed a single-cycle SRAM macro at transistor level: 6T bitcell array, 4-to-16 decoder with wordline-enable gating, bitline precharge, differential write drivers, and sense amplifier, sequenced by staged PRE / WE / WL / SE timing. Verified all 16 wordlines in pre-layout simulation — 28.0 ps worst-case write delay, 21.5 ps read delay, 197.4 µW.

Cadence Virtuoso, Spectre, 6T SRAM
